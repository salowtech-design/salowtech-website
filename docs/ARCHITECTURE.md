# Salowtech System Architecture

## 1. System Vision
Salow Technologies (https://salowtech.com) unified production architecture combining Astro 5 SSR/Static frontend with robust backend capabilities, database integration, and enterprise-grade SEO/AEO/GEO infrastructure.

## 3. Technology Stack
- **Frontend Framework:** Astro 5 (TypeScript, ESM)
- **Styling & Assets:** Vanilla CSS / Tailwind (preserved strictly from `salowtech-astro`)
- **Backend / API Engine:** Node.js ESM / Astro API Endpoints (`src/pages/api/*`)
- **Database:** Supabase / PostgreSQL
- **Deployment Target:** Vercel / Node Adapter
