# Salowtech Deployment & Infrastructure Guide

## 1. Target Environment
- Platform: Vercel / Node Serverless Adapter
- Node Engine: `>=18.0.0` (Targeting Node.js 20.x/24.x LTS)
- Package Manager: `npm`

## 2. Build & Start Commands
- Build: `npm run build`
- Dev: `npm run dev`
- Verification: `npm run verify`
