1. Run `node tools/server.js` from the project root and open http://localhost:3000 (or http://localhost:3000/crm-dashboard.html) to manage leads.
2. Required environment variables in `.env` (names only): `RECAPTCHA_SECRET_KEY`, `WEBHOOK_VERIFY_TOKEN`, and optional `PORT`.
3. This CRM dashboard and server tool is strictly for internal local use and is never included in the public Astro build or dist directory.
